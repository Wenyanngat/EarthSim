# Voluntas Devina

Copy this folder to the game's `mods` directory. Enable Voluntas Devina in the game's Workshop menu and restart the game. Code add-ons are disabled when first discovered.

The host selects Voluntas Devina below the main menu's version line, then chooses a seed, map size and terrain. The seed field starts with a generated value; Random generates another, and the field also accepts a seed entered by hand. The mode creates a two-seat LAN room. The second player joins from the game's Multiplayer menu using the host's LAN address. The world waits for both players before starting.

Select "Test match against a dummy" in the same setup form to start without a network room. The game creates two nations immediately. The dummy holds the second nation and takes no player actions. Both nations earn mana and use the same survival rule as the network match. Destroying the dummy's nation wins the test match. Losing your own nation ends it in defeat.

The game's startup help and tutorial offer stay hidden during a Voluntas Devina match. The ordinary game's help preference is unchanged.

Each player receives one nation. Both nations begin with the same population and urban value. The match opens on the 2D nations layer. The top bar keeps the year, world totals, time controls, menu and current mana. The mana meter remains at the bottom of the map. Players can choose another map layer without the mode switching it back. The match ends when only one assigned nation survives.

Open the action drawer with the handle at the middle of the right edge. The Benevolence tab offers Rain for 5 mana, Animals for 8 mana and Resources for 12 mana. Choose an animal species or resource type, select an action, then click a map cell. The Malevolence tab offers Hurricane for 20 mana, Flood for 24 mana, Earthquake for 30 mana and Meteorite for 45 mana. Each action uses brush size 1 and strength 1. The cost appears below each action. An invalid target, unavailable type or insufficient mana leaves the world and balance unchanged. The game keeps at most 40 active disasters; a new one replaces the oldest when that limit is reached.

This version targets Earth Simulator 2.2.0. Run it from a separate game copy while testing. Both clients need the same version of the mod.
