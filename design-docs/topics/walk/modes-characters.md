> ID `DOC-WALK-MODES-CHARACTERS`. Код поставки 2.1.4 и изолированные проверки. Наблюдения в запущенной игре остаются открытыми.

## Режим и снаряжение

Панель карты хранит `mode`, `god` и `rich` в `earthsim.walkopts`. Модуль входа принимает объект, вызываемый поставщик или сохранённое значение. Отсутствующее или неизвестное значение даёт `armed`. В `survival` оба флага нормализуются в `false`, а галочки скрываются. При возврате панели к `armed` виден прежний выбор. Настройки действуют до выхода из прогулки. Перенос внутри сцены сохраняет режим. Ключ `earthsim.walk` хранит чувствительность, состояние первой справки и вид от третьего лица. [SRC-144, SRC-146]

| Режим | Начало и изменение снаряжения | Боеприпасы |
| --- | --- | --- |
| Обычный (`armed`) | Набор из таблицы восьми ступеней. Доступность зависит от открытий и вытеснения оружия, с подстановкой `pre` при необходимости. Более высокая ступень заменяет набор, та же добавляет открывшиеся варианты, меньшая и ничья клетка после выдачи сохраняют текущий. К набору добавляются купленные позиции, пока список короче девяти. | `waAmmoHas` возвращает `Infinity` для указанного вида. Получение патронов на перезарядку оставляет запас профиля целым. |
| Выживание (`survival`) | Кулаки и зарегистрированные позиции `WKP.arms.owned`. Эпоха меняет облик. Получение и изъятие меняют личный набор. Изъятие удаляет также содержимое магазина этой позиции. | `reserve` расходуется по видам, `loaded` хранит содержимое магазина по позиции. Запас одного вида ограничен 999. Покупки в обычном режиме доступны в запасе при переходе к выживанию. |

`god` возвращает HP к максимуму при получении положительного урона до вызова обработчиков брони. `rich` даёт виртуальный баланс `10⁹` для `wkMoney` и пропускает списание через `wkPay`. Настоящий кошелёк остаётся доступным через `wkCash`. В сетевом пакете позы передаются облик, экипированная позиция и движение. Режим, флаги и профиль остаются локальными. Управление общим историческим временем проходит через отдельные права ведущего. [SRC-144, SRC-146, SRC-147]

## Сохранение персонажа

Сохранение карты записывает `ext.walk = {v: 2, cur, seq, chars: [{id, name, d}]}`. `cur` указывает выбранного героя, `seq` хранит счётчик ID героев. При записи активное `d` берётся из живого объекта `WKP`, остальные `d` берутся из их снимков. Профиль имеет версию 1 и следующие поля. [SRC-145]

| Поля | Содержимое |
| --- | --- |
| `purse`, `inv`, `arms` | Кошельки по `uid` эмитента, вещи, `owned`, `reserve`, `loaded`. |
| `quests`, `seq`, `jobT` | Задания, счётчик ID заданий этого профиля и срок повторной выдачи работы. |
| `rep`, `bounty`, `audience` | Слава и награды за голову по `uid`, допуски по клеткам. |
| `ext` | Данные модулей, включая настройки первых шагов. |

Старый одиночный `ext.walk` становится профилем первого героя. При отсутствии данных создаётся «Странник» с пустым профилем. При загрузке списка принимаются максимум 100 записей с уникальными ID от 1 до `10⁹−1`. Если `cur` отсутствует в списке, выбирается первая запись. Имя очищается и ограничивается 24 знаками. `wkpLoad` сохраняет идентичность объекта `WKP`, заменяет его поля и нормализует зарегистрированные позиции снаряжения. В сохранение героя входят данные таблицы выше. Позиция, HP, текущая сцена и её локальные часы создаются при входе. [SRC-145, SRC-146]

Создание выбирает нового героя, оставляя снимок прежнего. Смена возвращает состояние из снимка выбранного. Удаление активного выбирает следующего в списке, при его отсутствии предыдущего. Последнего удалить нельзя. «Чистый лист» очищает только активное `d`. Создание и очистка наследуют отметки подсказок ECO и текущее значение счётчика заданий. Смена загружает счётчик выбранного профиля. Модуль закона сбрасывает живой розыск и память стражи при смене, сохраняя `bounty` и `audience` выбранного героя. Новый мир и общий сброс заменяют список целиком. [SRC-145]

Создание, смена, удаление и сброс проверяют `walkActive` в самих функциях. Переименование через панель проверяет тот же запрет в `_wcCommit`. Функция `wkcRename` проверяет ID и имя. Изоляционные проверки прошли для миграции, записи в памяти, лимита 100 и блокировки панели при активной прогулке. [SRC-145, SRC-151]
