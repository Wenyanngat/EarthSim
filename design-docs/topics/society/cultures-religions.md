## Контракт и параметры [SRC-081]

W.culture/W.religion — Uint8-массивы меток населения клеток. CULTURES/RELIGIONS хранят записи по ID, нулевой элемент означает отсутствие. Политический владелец, культура, вера и династия — разные поля. Обычный setOwner не переписывает язык/веру; основание и колонизация имеют специальные записи.

| Параметр SOC | Значение | Действие |
| --- | --- | --- |
| STRIPES | 16 | Полный обход строк за 16 civ-тиков |
| ASSIM | .014 | База ассимиляции за обход клетки |
| DRIFT | .05 | Заимствование культуры ничейной клеткой |
| ETHNO | .0015 | Годовая попытка этногенеза |
| REL_SPREAD / REL_CONVERT | .30 / .025 | Обращение безверной / иноверной клетки |
| REL_STATE | .05 | Обращение в государственную веру |
| REL_FOUND / REL_MAX | .035 / 14 | Годовая попытка рождения / ориентир живых вер |
| SCHISM | .006 | Годовая попытка раскола |
| REVOLT / REVOLT_GAP | .04 / 40 | База восстания / годы между попытками |
| GOV_P | 1 | Частота реформ |

Новая культура: id=длина массива, имя, цвет, parent, born=floor(simYear), home=имя державы. При длине >=250 newCulture возвращает прежнюю культуру державы либо 1. Новая вера при длине >=250 возвращает 0; иначе хранит parent, holy=клетка, born, zeal=.7+random*.7, fol=0, dead=0. Это абсолютные пределы ID, отдельные от REL_MAX. Имена берутся через netNames из генератора культур/таблиц названий и ветвей; это не географический вывод из языка игрока [SRC-081].

_majority при основании/отделении суммирует pop+1 по ненулевой метке, а не просто число клеток. При равенстве итогов сохраняется первый достигший максимума по порядку обхода. Эта функция отличается от текущих счётчиков единства, суммирующих только pop [SRC-081, SRC-085].

## Полосный обход и единство [SRC-081]

На фазе ph=_socT%16 обрабатываются строки y=ph,ph+16,… . При ph=0 сначала публикуются результаты **предыдущего** круга: cultUnity=_sCul/_sPop, где отсутствующий числитель заменён 0; выбирается наиболее населённая ненулевая вера и принимается как государственная лишь при доле >.5. Без государственной веры relUnity=1, иначе доля её последователей. При _sPop<=0 прежнее единство остаётся.

Затем накопители обнуляются, публикуются fol каждой веры и общий _socWorld, и начинается новая полоса. Итог не является одним мгновенным снимком: разные строки и меняющиеся границы считались в разные civ-тики. Стабильность текущего тика рассчитана ещё до societyTick.

У клетки pop<5 обе метки очищаются. Отдельного исключения воды в societyTick нет. Для pop>=5:

1. При владельце и c=0 культура сразу становится st.culture. Чужая ненулевая культура ассимилируется с вероятностью `.014*(.4+stability)/(1+pop/15000)`.
2. Выбирается один случайный сосед NB8. Ничейная клетка без культуры при pop>=40 может взять его ненулевую культуру с вероятностью .05.
3. Вера соседа допускается, если его pop>40, вера ненулевая и другая. База .30 при r=0, .025 при иноверии, умножается на zeal источника. Если это государственная вера получателя — ещё *2.5; если старая вера получателя государственная — *.35.
4. После соседской ветви государственная вера может обратить клетку с вероятностью .05, а при era>=6 — .015. Поэтому она может перезаписать только что принятую соседскую веру в тот же вызов.
5. Уже новые метки попадают в счётчики единства/последователей; изменения происходят на месте, без общего буфера.

Соседняя клетка без населения не является источником даже при ненулевой метке. При старой/неизвестной записи веры zeal заменяется 1; отдельного запрета dead в этой ветви нет [SRC-081, SRC-085].

## Рождение, принятие, раскол и возвращение веры [SRC-081]

В годовом обходе держава без государственной веры при era>=1 и cityCount>=1 может основать её, если снятый перед циклом relAlive<14 и random<.035. Столица получает новую веру всегда, прочие клетки с вероятностью .35; relUnity временно ставится .4. holy хранит клетку основания, не динамическую столицу.

relAlive рассчитывается **один раз перед обходом**. Две державы могут обе пройти лимит при исходных 13 верах и создать 15; проверка P37 воспроизводит именно эту границу. Это ориентир разрешения попыток, а не жёсткая финальная отсечка [SRC-081, SRC-085].

На фазе 0 вера без последователей (fol<1) становится dead лишь когда simYear−born>5. Мёртвая запись при fol>0 оживает; запись не удаляется. Новый fol отражает прежний полосный круг, поэтому смерть/возвращение тоже имеют задержку.

Раскол рассматривается после годового обхода, если _socWorld>0 и прежний relAlive<14. Первая живая вера с fol>.30*_socWorld, возрастом >120 и броском <.006 вызывает _schism; после этого цикл прерывается, даже если подходящей державы не оказалось. Кандидат — живая держава этой веры, area>=6 и не владелец holy-клетки. Одна случайная кандидатура получает дочернюю веру, её клетки старой веры переходят с вероятностью .7. Это не автоматическое отделение территории [SRC-081].

## Этногенез и национальное восстание [SRC-080, SRC-081]

Этногенез: area>=5, возраст державы >120 и бросок <.0015; затем проверяется, что не менее трёх живых держав имеют ту же культуру. Возникает дочерняя культура с parent=старый ID; сама держава принимает её, клетки прежней культуры меняются с вероятностью .75. Из-за последовательной обработки изменение первой державы может убрать третьего носителя для следующей.

Попытка национального восстания: area>=8, cultUnity<.8, simYear−(_revoltY||−1e9)>40, бросок `<.04*(1-cultUnity)*(1.2-stability)*2`. _revoltY записывается **до** отбора пригодного куска; даже неудачная попытка расходует паузу. Нулевая дата имеет ту же особенность ||, что у реформ.

Чужие культуры группируются по числу клеток, выбирается самая большая группа, затем её крупнейшая 8-связная компонента. Нужны >=4 клетки, суммарный pop>=1400 и отсутствие столицы. Не выбирается следующий народ/компонента, если первая не прошла. Если рядом по _nb есть живая держава этого народа, бросок <=.5 и фактическое касание NB8, кусок переходит ей, unrest=0, отношения с метрополией уменьшаются на .4. Иначе при aliveCount<stateCap*1.25 создаётся независимая держава через secedeChunk. Если центр жив, stability>.45 и random<.35, объявляется война независимости. Полные битвы остаются военному пакету [SRC-080].

## Локальные визуальные потребители [SRC-084]

cultureRoot/religionRoot проходят не более 16 родительских связей. Потомки наследуют архитектурную семью корня; archOfCulture/templeStyleOf вычисляют её детерминированно. archStyleAt дополнительно использует средние температуру/осадки: t>21 и p<650 дают южную семью 3, t<2 — северную 0, южная при p>1400 меняется на 1. При prev проверяются четыре поправки ±1.5 °C и ±80 мм: если прежняя семья возможна в этом окне, она сохраняется. Это локальный код выбора, не наблюдение рендера/прогулки.

## Сохранение [SRC-084]

ext.society хранит культуры без нулевого элемента: имя/цвет/parent/born/home и необязательное исходное имя. Веры хранят также holy, zeal с двумя десятичными знаками, округлённый fol, dead и необязательное исходное имя. _socT/_socWorld и полосные накопители не сохраняются; после загрузки начинаются заново.

При отсутствии ext.society очищаются клеточные метки, каждой живой державе назначается новая культура, вера 0 и строй по эпохе: era>=6 — демократия при stability>.5, иначе диктатура; era>=4 — республика; era>=1 — монархия; ранее — вождество при area>6, иначе племя. _KEEP_U обычного сейва сохраняет _golden/_govY/_revoltY/_unionY/_vasT/_lostToUid, если значения конечные числа. Проверен обычный roundtrip в памяти; дисковая атомарность и сетевой контракт здесь не установлены [SRC-084, SRC-085].
