## 2\. Основная игра · Начальная подсказка

После создания мира поверх карты появляется окно «Как играть — Симулятор Земли». Оно объясняет роль игрока как создателя планеты, знакомит с интерфейсом и предлагает первые действия. Карта позади окна визуально приглушена.

![][image12]

Рис. 11\. Стартовая подсказка поверх игрового интерфейса.

### Содержание обучения

* Инструменты: Земля, Климат, Жизнь и Стихии. Подсказка перечисляет примеры их воздействия на мир.  
* Первое действие: поселить людей на зелёной плодородной земле и ускорить время; сёла могут вырасти в города, а города — в державы.  
* Связи симуляции: ветер переносит дождь, течения влияют на побережья, засуха вызывает голод, а ресурсы влияют на развитие обществ.  
* Наблюдение: статистика, хроника, династии, войны, настройки планеты и тематические слои.  
* Исследование: объёмный вид 3D и прогулка по миру от первого лица.  
* Названия земель: народы называют территории самостоятельно; игрок может задавать названия инструментом или клавишей N.

Внизу доступны флажок «Не показывать при запуске» и кнопка «Начать игру». Повторный доступ к справке и обучению предусмотрен в настройках.

## 2\. Основная игра · Быстрый доступ

### Горячие клавиши стартовой подсказки

| Клавиша | Действие |
| :---- | :---- |
| Пробел | Пауза. |
| Tab | Переключение 2D / 3D. |
| F2 | Статистика. |
| L | Хроника. |
| D | Династии. |
| V | Войны. |
| F5 / F9 | Быстрое сохранение / быстрая загрузка. |
| 1–0 | Выбор инструментов; соответствие конкретных цифр инструментам здесь не раскрыто. |
| \[ / \] | Изменение размера кисти. |
| Колесо мыши | Масштабирование карты. |
| Esc | Меню. |
| N | Названия земель; указано в тексте подсказки. |

### Расположение интерфейса

Центральную область занимает карта. Сверху расположены показатели мира и управление временем. Слева находятся инструменты и генерация нового мира. Справа — переходы к информационным окнам и сведения о клетке. Снизу — тематические слои природы и общества, а также легенда отображения.

Такое расположение поддерживает два основных действия: изменение мира через левую панель и наблюдение за результатами через карту, правую панель и слои. Выбор режима «Осмотр» позволяет перейти к наблюдению без изменения мира.

## Интерактивное обучение и подсказки

Стартовая справка `coach` открывается при запуске интерфейса, если `earthsim.hideHelp` не равен `1`. Её можно открыть кнопкой справки, клавишей F1 или из настроек. Отдельное предложение пройти тур проверяется каждые 1100 мс. Оно ждёт готового мира, закрытия справки и меню и не предлагается в сетевой игре. «Не сейчас», «Пропустить» и завершение тура записывают `earthsim.tutorialDone=1`. Кнопка в настройках запускает тур вручную с первого шага. [SRC-236]

| Шаг | Автопереход |
| --- | --- |
| 1. Знакомство | По кнопке |
| 2. Высота, группа «Земля» | Нажатие по 2D- или 3D-карте с инструментом высоты, рельефа или воды |
| 3. Заселение, группа «Жизнь» | Есть хотя бы одна клетка с населением >0 |
| 4. Ускорение времени | Скорость ≥10 |
| 5. Слои карты | Выбранный слой сменился по сравнению со входом в шаг |
| 6. Рождение держав | Есть живая держава |
| 7. Осмотр | Открыто окно интерфейса |
| 8. Статистика, хроника, династии и войны | По кнопке |
| 9. Стихии и силы творца | По кнопке |
| 10. 3D | Включён 3D-режим |
| 11. Прогулка | По кнопке |
| 12. Цели и меню | По кнопке |
| 13. Окончание | «Играть» |

На каждом шаге доступна кнопка перехода или завершения. Автопереход опрашивается раз в 700 мс и приостанавливается открытым главным меню. На шагах рисования и осмотра подсветка пропускает нажатия по карте. [SRC-236]

Подсказки включены по умолчанию. `earthsim.hints` хранит переключатель, `earthsim.hintSeen` хранит показанные подсказки. Опрос идёт раз в 1500 мс. Показывается первое выполненное условие по порядку списка, только одна подсказка за раз. Она отмечается просмотренной при показе и автоматически скрывается через 9 секунд. [SRC-236]

| Подсказка | Условие |
| --- | --- |
| `firstState` | Живая держава |
| `firstCity` | Хотя бы один город |
| `geoNames` | Появилось автоматическое название земли или моря |
| `firstRuler` | Запись хроники `ruler` или `dynasty` |
| `firstWar` | Запись `war` |
| `disaster` | Запись `disaster` или `plague` |
| `famine` | Запись `famine` или `exodus` |
| `extinct` | Запись `extinct` |
| `era3` | Живая держава достигла порога заводов `CIV.AT_FACTORY` |
| `seaLevel` | Уровень отличается от первого замера модуля больше чем на 0,0009 |
| `speed20` | Год >25 при скорости ≤1 |
