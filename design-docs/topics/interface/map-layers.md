## 2.4. Нижняя панель · Слои карты

Нижняя панель переключает тематическое отображение мира. Она разделена на строки «Природа» и «Общество». Слои позволяют рассмотреть один аспект симуляции: климат, экологию, население или политическое устройство. По исходному описанию они используются при просмотре карты в 2D и 3D.

## Поля, шкалы и прозрачность

Смена темы записывает `uiState.layer` и `currentOverlay`, выбирает одну легенду и помечает слой грязным. В 3D вызывает `bakeTerrain`. Подсистемы используют `registerLayer` для цвета `cell(i, out)`, легенды, подписи и текста в подсказке. `smooth` выбирает плавное 2D-поле, остальные зарегистрированные слои используют области по взвешенной близости центров. `sea` разрешает данные над водой, `borders` включает границы, `veil` затемняет подложку. [SRC-136]

| Слой | Источник цвета или символов |
| --- | --- |
| Биомы | Основной рельеф окрашен по `BIOME_RENDER`, растительности и деталям поверхности. Легенда показывает до шести сухопутных биомов по площади. Присутствующая выжженная пустошь ставится первой. |
| Температура | Текущее `W.temp`, шкала от −30 до +45 °C. В 2D изолинии −30, −20, −10, 0, 10, 20, 30, 40. |
| Осадки | Текущее `W.precip`, 0…3000 мм/год, отсечение над водой. Изолинии по суше 250, 500, 1000, 1500, 2000, 2500. |
| Ветер и течения | Векторы полей атмосферы и воды. В 2D течение над водой окрашивается по температуре, ветер по силе. Указатель показывает скорость и направление. |
| Экология | `W.eco` по суше, коричнево-зелёная шкала. |
| Загрязнение | Смог `W.pollution>0,02`. В 2D `W.fallout>0,02` выводит отдельную заливку поверх смога. 3D-функция `overlayCell3D` этого специального цвета для выпадений не вычисляет. |
| Население | Суша при `pop>30`. Насыщение через `log(pop)/log(120000)`, цвет от жёлтого к красному. |
| Державы и битвы | Цвет живого владельца, границы, выделение и метки событий. Легенда держав берёт до шести крупнейших по населению. |
| Народы и веры | Цвет по ID культуры или религии на суше, границы и подписи областей. Отсутствующий ID оставляет клетку прозрачной. |
| Развитие, богатство, порядок | Развитие интерполирует пять цветов по `tech/CIV.TECH_CAP`, богатство использует `log10(max(gdpPc,250)/250)/1,7`, порядок — `stability` владельца. |
| Эпидемии | Индекс `disease` по суше при ≥0,02. Цвет и непрозрачность растут с `clamp01(1,6·disease)`. |
| Недра | Цвет из `RES` при ненулевом индексе. Водная клетка допустима. Легенда показывает все зарегистрированные ресурсы. |
| Животные | В воде бирюзовая шкала `fish`, на суше зелёная яркость от `sqrt(1,7·herb)` со смесью рыжего от `pred`. Подсказка получает данные модуля фауны. |
| Торговля | Зарегистрированный слой использует интенсивность путей, узлы и сведения `tradeUi`. Щелчок может открыть путь или карточку торговли. |

2D-рендер ограничивает DPR сверху 2, ширину буфера 2560, сохраняя пропорции карты. Вода освежается каждый третий кадр или после изменения вида. Суша запекается для видимого прямоугольника, под ней есть грубая целая карта. При мазке грубый проход выполняется в половинном разрешении, подробный фон собирается порциями. Прозрачные соседи плавного слоя учитываются в билинейной выборке с весом по альфе. При смене слоя или попадании грязной пометки слой перестраивается, иначе ждёт нового `simTick` и прохода по счётчику кадра. Кэш областей отдельно реагирует на выбор, наведение, рельеф и динамику. [SRC-136, SRC-143]

3D получает цвет зарегистрированных слоёв от того же `cell(i,out)` и добавляет заливки выбранной и наведённой держав. Для встроенной температуры, осадков, населения и экологии цветовые шкалы близки к 2D, но альфа и порядок выборки различаются. Возврат в 2D ставит пометки подложке и границам, потому что 3D мог обработать их ранее. [SRC-135, SRC-136, SRC-143]

## Независимые обозначения

`MAP_OV` хранит отдельные переключатели городов, общих имён, имён народов, настоящих имён Земли, дорог, железных дорог, морских путей, судов, воздуха, портов, аэродромов и баз. Умолчания включены. Хранение локальное в `earthsim.mapov`, изменения передаются в `mapOv3DApply`. Выключение имён скрывает подписи карты, поиск названия для инспектора остаётся доступен. [Имена мест](../simulation/real-earth.md) [SRC-136, SRC-138, SRC-143]

## 2.4. Легенда и дальнейшее уточнение

### Легенда текущего отображения

![][image18]

Рис. 17\. Легенда слоя «Биомы».

В правом нижнем углу показана легенда «Биомы»: цветные маркеры сопоставлены названиям типов местности. На снимках интерфейса перечислены ледник, пустыня, альпийские луга, болото, тундра, холодная пустыня и степь. По исходному описанию легенда отражает биомы, присутствующие в текущем мире; перечень не является полным каталогом биомов игры.

Далее подробно описаны окна государства, города и персонажей, а также журнал и управление в режиме прогулки. Значения на снимках иллюстрируют конкретную партию: они не являются стартовыми параметрами или постоянными величинами игры.
