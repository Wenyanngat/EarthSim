## 2.5.4. Города государства

Вкладка содержит реестр городов выбранной страны. Над таблицей показаны количество городов, суммарное население в них и его доля в населении государства. Клик по строке показывает город на карте — это прямо указано в подсказке.

![][image28]

Рис. 27\. Реестр городов державы.

| Поле | Назначение |
| :---- | :---- |
| Город | Название поселения; в примере столица Verona отмечена звездой. |
| Население / Горожан | Население клетки и min(население, городская ёмкость), округлённые для показа [SRC-013, SRC-070]. |
| Основан / Основатель | Год основания в хронологии симуляции и основавшая город держава. |
| Пик | Пиковая численность населения, показанная для города. |
| Промышл. / Загрязн. | Показатель промышленности и процент загрязнения. |
| Континент | Континент, на котором находится город. |

Стрелка возле заголовка отмечает текущий порядок сортировки. Подробное окно города описано в разделе 2.6: оно дополняет реестр природными условиями, жителями и действиями игрока.

**Проверено по реализации [SRC-013]:** в таблице «Население» — население клетки города, «Горожан» — минимум населения и городской **ёмкости** клетки. `W.urban` не является отдельным счётчиком людей: если ёмкость ниже числа жителей, остальные не входят в показанное число горожан. В карточке города то же правило применяется непосредственно к `W.pop` и `W.urban`; оба числа округляются для вывода. Доля урбанизации **всего государства** вычисляется иначе: сумма городских минимумов для крупных городов, 60% минимума при urban>300 в остальных клетках, делённые на общее население [SRC-070, SRC-071]. Поэтому сумму строк «Горожан» городского реестра нельзя без проверки приравнивать к государственному проценту урбанизации.

## Уточнённая модель городов [SRC-070–072]

[Полные формулы](../simulation/demography-cities.md): места выбираются по устойчивой оценке и зазору, бюджет избытка делится 86% выбранным местам и 14% прочим клеткам. Это меняет urban, без прямого переноса pop. cityCount государства снимается раньше новой аллокации и не исключает воду; финальный cities исключает воду. Поэтому реестр и прежний агрегат могут кратко расходиться. 45 изолированных проверок не заменяют наблюдение интерфейса.

## Экономические входы [SRC-073–078]

[WP-ECONOMY-TECH](economy.md) прослеживает ВВП/казну/науку/промышленность. Государственная агрегация предшествует новой городской аллокации; локальная наука предшествует поздней передаче знаний. 41 изолированная проверка прошла; runtime не наблюдался.
