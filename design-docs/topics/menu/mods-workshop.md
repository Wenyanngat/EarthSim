## 1.7. Мастерская Steam

Официальный демонстрационный пакет example-pack (`EarthSimulator/mods/example-pack/mod.json`) помечен выключенным по умолчанию; его примеры не считаются правилами базовой игры без проверки загрузчика [SRC-003].

Экран управляет установленными дополнениями: их активностью, локальными файлами и переходом к страницам Steam Workshop.

![][image9]

Рис. 8\. Установленные дополнения и действия мастерской.

### Строка дополнения

Слева расположен флажок включения. В центре — название и сведения об авторе, источнике и числе сценариев либо статусе. Для дополнений из мастерской доступна «Страница в Мастерской». В строке локального примера показаны действия «Изменить», «Опубликовать», «Удалить»; в данном состоянии они приглушены.

### Основные действия

* «Создать дополнение» — переход к созданию собственного дополнения; «Перезапустить игру» — отдельное действие перезапуска.  
* «Открыть Мастерскую», «Папка модов», «Обновить» и «Закрыть» расположены внизу окна.  
* Флажок позволяет отключить дополнение без отписки, в том числе для раздельного использования конфликтующих наборов.

### Правила из пояснения экрана

Собственное дополнение удаляется вместе с папкой на диске. Подписку Steam Workshop снимают на странице предмета: простое удаление файлов не предотвращает повторную загрузку Steam. Локальные моды размещаются в папке mods рядом с игрой; дополнение представляет собой папку с mod.json. Подписки подхватываются автоматически, но дополнение с кодом после подписки остаётся выключенным до ручного включения.
