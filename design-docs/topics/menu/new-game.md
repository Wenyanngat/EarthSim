## 1.1. Новая игра

Преобразование параметров в высоты, берег, биомы и ресурсы описано в темах [«Генерация мира, рельеф и недра»](../simulation/world-terrain.md) и [«Реальная Земля»](../simulation/real-earth.md). [SRC-118, SRC-119, SRC-125]

Экран задаёт исходные условия новой симуляции. Настройки распределены между блоками «Мир», «Климат старта» и «История». Верхняя строка предназначена для выбора и управления наборами настроек.

### Наборы настроек

Игрок выбирает готовый или собственный набор, сохраняет текущую конфигурацию, переименовывает или удаляет выбранный набор и возвращается к значениям «По умолчанию». В показанном состоянии выбран пункт «Текущие настройки»; переименование и удаление визуально недоступны.

### Параметры мира

* Размер карты — габариты сетки мира; показан вариант «Обычная — 80×60». Более крупные карты требуют больше времени на расчёты.  
* Рельеф — шаблон формирования суши; на скриншоте выбраны «Континенты».  
* Животный мир — настройка исходной фауны; показано значение «скудный».  
* Зерно мира — случайное либо введённое игроком значение. Одинаковое зерно при одинаковом размере воспроизводит рельеф, но не гарантирует одинаковую историю мира. Текущее зерно выведено отдельной строкой.

## 1.1. Новая игра · Климат и история

### Климат старта

| Параметр | Что задаёт | Пример на экране |
| :---- | :---- | :---- |
| Уровень моря | Начальное положение уровня воды относительно высот рельефа. | 0 м |
| CO₂ (парниковый эффект) | Исходную концентрацию углекислого газа, связанную с парниковым эффектом. | 280 ppm |
| Светимость Солнца | Множитель светимости, задающий условия нагрева планеты. | 0,92× |

Каждый параметр представлен ползунком и числовым значением справа. Единицы измерения сохраняются в интерфейсе: метры, ppm и множитель светимости.

### Развитие истории

* Темп истории — отдельный множитель исторического развития. В исходном описании указан диапазон 0,4–2,6; на скриншоте выбран 2,6×. Под ползунком приведена ориентировочная длительность пути от племён до космоса.  
* Самозарождение жизни — включение самостоятельного возникновения жизни в мире.  
* Стихийные бедствия — выбор режима природных катастроф; показано значение «как в природе».  
* Сразу заселить первые племена — запуск мира с начальным человеческим населением.  
* Живой уровень моря — связь уровня моря с потеплением и похолоданием. Таяние льда поднимает воду и затапливает низины, охлаждение обнажает шельф.

### Запуск и возврат

«Создать мир» запускает генерацию по выбранной конфигурации. «Отмена» и крестик закрывают экран настройки. Подсказка сообщает, что параметры истории и климата можно менять во время игры через окно «Планета».

Форма собирает размер, тип, темп, бедствия, живой уровень моря, заселение, богатство фауны и её самозарождение. Зерно передаётся при `0 < seed < 2147483647`. Климатические поля включаются, если числовое значение отличается от соответствующего умолчания на величину больше `1e-6`. При возврате ползунка к умолчанию поле снова отсутствует. Стартовое заселение для `empty` и `flat` выключается. Действие пишет конфигурацию перезагрузки и пробует автосохранить прожитый мир. Отказ автосохранения не блокирует перезагрузку. При новом старте загружается подготовленный мир дополнения либо строится рельеф, затем применяются климат и история. Первые племена добавляются при включённой опции вне сценария. [Жизненный цикл меню](lifecycle.md) [SRC-019–020, SRC-110, SRC-112, SRC-117]

### Различие двух настроек времени

Темп истории задаётся в конфигурации мира. Скорость ×1–×50 в игровом интерфейсе умножает время, поступающее в климатический и цивилизационный планировщики. `W.pace` используется профильными алгоритмами, интервалы планировщика составляют 166/430 мс. Применение переданных климатических полей запускает прогрев и повторное событие `worldgen`, даже если переданное число совпало с текущим. В изолированной проверке после `worldgen('flat',1)` вызов `_applyBootParams({co2:1})` оставляет год 0,1 без годового события. [Базовая симуляция](../simulation/baseline.md) [SRC-059–061, SRC-110]

## Умолчания формы и встроенные наборы

Умолчания формы из разметки — 80×60, континенты, обычная фауна, самозарождение и первые племена включены, бедствия «как в природе», живой уровень моря включён, случайное зерно, море .40, CO₂ 280 ppm, Солнце 1× и темп истории 1×. Готовые размеры 60×45, 80×60, 120×90, 160×120, 200×150. Пользовательский размер 24…220 по каждой оси. Пределы формы для уровня моря .25… .60, CO₂ 112…896 ppm, светимости .88…1.12, темпа .4…2.6. Подсказка истории округляет `850/pace` до 50 лет. Прямое изменение фауны на «нет животных» снимает самозарождение, повторное включение разрешено. [SRC-112, SRC-117]

| Набор | Изменения относительно умолчаний |
| --- | --- |
| Быстрая партия | 60×45 и темп 1.6 |
| Большая Земля | 120×90 и реальная Земля |
| Долгая эпопея | 160×120 и темп .6 |
| Архипелаг | 120×90, острова, море .44 |
| Холодная планета | CO₂ .7 от базового, светимость .96 |
| Жаркая планета | CO₂ 2 от базового, светимость 1.04 |
| Чистый холст | Ровная суша без первых племён и стихийных бедствий |

Наборы игрока хранятся как `{n,v}` в `earthsim.ngPresets`. Лимит 30 записей, имя до 40 символов после нормализации пробелов. Сравнение без учёта регистра. При чтении повреждённые записи отбрасываются, повторяющиеся имена оставляют первую запись. Зерно входит в пользовательский набор. `earthsim.ngLast` обновляется при нажатии «Создать мир» до попытки перезагрузки и хранит последние параметры без зерна. При построении меню эти параметры заполняют форму. [SRC-112, SRC-117]

Выбор набора сразу заполняет форму. Изменение параметра сбрасывает пункт на «Текущие настройки». Переименование и удаление включены для выбранного пользовательского набора. Запись под занятым именем, замена при конфликте переименования и удаление требуют подтверждения. «По умолчанию» применяет значения разметки. Отказ записи оставляет сообщение и сохранённые настройки в прежнем виде. [SRC-112, SRC-117]

## 2.2.0 world rules and history

New Game configures rules before historical settlement. The Rules tab in Planet changes the rules for an existing world. An active scenario or rivalry locks live edits. In a room, the host issues the rules command and the copies apply it on the shared turn. [SRC-284]

| Rule | Effect |
| --- | --- |
| No wars | Enabling it in a live world ends existing wars with white peace. The UI asks first when wars are active. It blocks ordinary new declarations. The creator's forced actions can still intervene. |
| No revolts, no alliances | The first blocks ordinary revolts and specified breakup paths. The second keeps ordinary relations below the alliance threshold and removes bloc membership. Vassal ties and registered player pacts are exempt from the relation clamp. |
| Era and starting era | A ceiling limits future progress without lowering already reached eras. Fixed era keeps each polity in its own era. A starting era raises newly founded polities, subject to the ceiling. |
| Fixed biomes, collapse, polity count | Fixed biomes stops automatic biome changes. Collapse offers the historical, rare and never settings. The optional cap blocks automatic founding at the selected count of 2–200 live polities. A cap of 0 removes it. |

New Game can pin atmospheric CO₂ and sea level. The Planet controls can also pin global temperature after the world initializes. History pace can range from 0.2× to 4×, and the New Game economy settings let the player set research costs by era. [SRC-284, SRC-286]

The Ancient World preset selects Real Earth at 120×90, with historical settlement enabled. The historical option appears for Real Earth. A bundled add-on world restores its own history and calendar from the save. [SRC-285]
