# Документация Earth Simulator

Приоритет извлечения: база, фауна, демография, экономика, политика, династии, торговля, войны и территории. Порядок восьми этапов и минимальные предчтения зависимостей зафиксированы в [плане](EXTRACTION_PLAN.md) и [JSON охвата](research/feature-scope.json).

Версия исследованных установленных файлов — **2.1.4** по `EarthSimulator/package.json`, а не результат нового запуска. Игра использует NW.js и JavaScript; точка загрузки — `EarthSimulator/index.html`. Наблюдений в запущенной игре нет.

7. [RESEARCH_STATE.md](RESEARCH_STATE.md) — точка продолжения; [CHANGELOG.md](CHANGELOG.md) — история изменений.

В предыдущих проходах визуально просмотрены **11 различных снимков из 46**; этот проход посвящён структуре документов.

## Каталог и его обновление

Пути в JSON считаются от корня проекта. `documents[].id` и `features[].id` — стабильные идентификаторы; `features[].document_ids` и `documents[].feature_ids` задают двусторонние связи. Каждая фича имеет краткое описание, статус документации, статус исследования, SRC-источники, точки входа в код и открытые вопросы. Служебные документы и неизменённый исходник тоже включены в список документов.

`research_status` **не означает готовность фичи**. `partial` — частичный статический разбор, `not_researched` — исполняемый путь не исследован. `documentation_status` различает подробный текст, упоминание и каркас. Наличие модуля не доказывает доступность режима. Все `runtime_verified` равны `false`.

После правок тематических документов обновлять связанные записи каталога. При новых фактах обновлять также источники, покрытие, вопросы и точку продолжения. Проверка из корня проекта:

```powershell
$env:EARTHSIM_REFERENCE_ROOT = '<папка эталонной установки>'
$env:EARTHSIM_EVIDENCE_ROOT = '<папка, содержащая .research>'
python design-docs/tools/validate_catalog.py
python design-docs/tools/validate_feature_scope.py
```

Эталонная установка содержит `EarthSimulator/`. Вторая переменная нужна, если архив проверок `.research/` хранится отдельно от установки. Относительные пути к этим файлам указаны от корней соответствующих папок.

Описание разделов и ссылки на документы находятся в [указателе](GAME_DESIGN.md).

## Правила доказательств

Абзацы без SRC-ссылок — только утверждения прежнего документа [SRC-012]. Метки прежних проходов: **реализация** — прослеженный исполняемый путь; **интерфейс** — элемент без подтверждения результата; **исходник** — прежний текст; **наблюдение** — воспроизведённый опыт; **предположение** и **неизвестно** — не доказаны.

Официальный example-pack (`EarthSimulator/mods/example-pack/mod.json`) выключен по умолчанию. Примеры модов не являются правилами базовой игры без проверки загрузчика. Сохранения и настройки пользователя не изменялись.
